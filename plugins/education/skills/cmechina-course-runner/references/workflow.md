# CMEChina 流程说明

## 页面状态

- `study2.jsp`：小节视频页。读取 `video.currentTime`、`duration`、`paused`、`ended` 和 `playbackRate`。
- `exam.jsp`：小节考试页。提取每个 `h3.name` 及其同一题目内的单选框。
- `examQuizFail.jsp`：未通过结果页。URL 和页面会指出错误题目序号；重试前先利用该反馈。
- `examQuizPass.jsp`：通过结果页。点击可见的 `继续学习下一节` 链接。
- `examCoursePass.jsp`：最后一节通过页，状态为 `course-pass`；`advance` 返回课程列表，不自动申请学分。
- `course.jsp`：课程列表页。读取 `progress.sections`，进入第一节未通过的小节；没有识别到小节或状态文字时停止检查，不推断全部完成。

## 单网址运行与恢复

所有命令均支持 `--url '用户课程网址'`，脚本校验域名并提取唯一课程 ID。每轮先 `status`，然后消除普通弹窗，再按页面分派：

- `video`：`arm --resume`；健康播放时交给结束事件和 10 分钟 heartbeat。已经 ended 时当轮等待考试入口跳转并处理考试，不留到下一轮。
- `exam`：提取完整题目与选项，依据课程内容；涉及医学知识且需要核实的题目用权威原始来源查证。答案不确定时通知用户，不猜测或穷举。
- `fail`：读取错误反馈，最多两轮有依据的修正；仍失败则报告题目和阻塞原因。
- `pass` 或 `course-pass`：`advance` 后重新读取状态；不要假设跳转目标。
- `course`：`progress.allPassed` 为真则完成，否则 `advance` 后等待视频就绪并挂载监听器。
- 登录页、其他未知页面、受保护提示、状态缺失：检查一次真实页面；无法明确恢复时通知用户。

监测提示词应包含原始网址、skill 路径、上述状态分派、10 分钟恢复频率、普通签到处理、健康播放静默和完成后删除任务。每轮进度从页面读，禁止硬编码起始节数或已完成数量。只允许一个同课程监测任务；执行前重读状态，以免手动操作或其他任务已推进导致重复提交。

## 视频结束事件

视频完成必须以媒体元素的 `ended` 状态或事件为准。不得根据现实时间或监测频率估算完成时刻。

辅助脚本使用 `video.dataset.codexEndedExamArmed` 标记当前视频。页面或视频元素变化后，该标记和监听器都会消失，因此每次进入新小节都要运行 `arm --resume`；监测任务发现标记缺失时也应重新挂载。

监听器会延迟约 1.5 秒点击考试入口，让网站自身的完成处理先执行。若入口尚未渲染，它会以有限次数重新查找；只有实际点击后才记录 `codexEndedExamFired`。`codexEndedExamAction` 会显示 `waiting`、`clicked` 或 `not_found`，用于避免重复点击和排查问题。

## 安全提交答案

`select` 只选择单选框，不提交试卷。它要求每道显示的题目恰好对应一个答案，并返回已选值供检查。任何题目未作答时，`submit` 都会拒绝提交。

提交后以结果页为准。满分通过后才能继续；未通过时，只能根据网站指出的错误题目进行有限修正，再使用 `retry` 返回试卷，禁止穷举答案组合。

## 过程签到

课程页面可能出现“过程签到”标记并暂停视频。`status` 的 `signin` 字段为 `true` 表示存在文字严格等于“签到”的可见入口。`dismiss` 应直接点击该按钮；视频页观察器也应在按钮动态出现时处理，然后重新检查页面并恢复正常播放与结束监听。签到控件即使不在已识别的弹窗容器内也要点击。

若签到界面同时出现人脸、实名、验证码、“本人操作”或“学员本人”等身份验证特征，则不属于普通流程标记：将其加入 `blocked`，暂停并通知用户。

## 页面弹窗

`dismiss` 扫描可见的站内对话框和常见遮罩层，只点击语义明确的关闭类控件，并返回：

- `dismissed`：已点击的按钮及弹窗摘要；
- `unhandled`：没有安全关闭按钮、需要重新检查或由用户处理的弹窗；
- `blocked`：登录、身份核验、明确的本人操作、考试提交、支付、授权等受保护弹窗；普通签到标记不在此列。

`arm --resume` 会先执行一次相同扫描，并为动态插入或重新显示的弹窗安装 `MutationObserver`。观察器只属于当前页面；导航、刷新或进入下一小节后必须重新运行 `arm --resume`。若返回 `PROTECTED_POPUP`，视频会暂停，后续流程必须等待用户本人处理。浏览器原生 JavaScript 对话框、权限提示和操作系统弹窗不在页面 DOM 中，不得用系统级盲目按键自动确认。

## 周期监测

用户要求持续监测时，如产品支持，应使用当前线程的 heartbeat。它负责：

- 根据域名和课程 ID 找到课程标签页；
- 检查真实页面与视频状态；
- 消除普通站内弹窗；遇到受保护或无法识别的弹窗时停止并通知；
- 在结束监听器缺失时重新挂载；
- 处理考试页和结果页；
- 进入下一节未完成课程并挂载其视频监听器；
- 视频健康播放时保持安静。

若页面已经是 `exam.jsp`，必须在同一轮立即提取题目并进入答题流程，不能仅记录为“已到考试页”后等待下一轮。

Heartbeat 的频率只是恢复检查间隔，不是完成检测器。只有小节通过并进入下一节、全部完成、发生错误或需要用户操作时才通知。
